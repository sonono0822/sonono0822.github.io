# Season Specification

## Current State

Seasonal presentation exists but is still limited.

Status: **Partially implemented / improvement planned**

## Direction

Continue improving seasonal differences gradually.

Seasonal effects should:

- fit the existing background world
- remain subtle enough not to overwhelm the clock/calendar
- avoid excessive decorative complexity
- remain compatible with long-duration display

## Expected Code Mapping

- CSS: `season.css`
- JS: `season.js`

If actual repository filenames differ, use `FILE_MAP.md`.
