# Clock Specification

## Scope

The clock is one of the two primary functions of Pixel Desk Clock.

## Current Direction

- Prioritize readability.
- Preserve the current pixel-art visual direction.
- Keep it comfortable for long-duration viewing.
- Do not redesign the clock unless the task explicitly targets the clock.

## Change Rule

If the task is unrelated to the clock, do not modify clock logic or styling.

## Expected Code Mapping

- CSS: `clock.css`
- JS: `clock.js`

If actual repository filenames differ, use `FILE_MAP.md`.
