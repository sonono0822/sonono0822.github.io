# Layout / UI Specification

## Basic Layout

- Left: large clock
- Right: calendar
- Background: pixel-art room and city/outdoor view
- Bottom area: small character
- Dialogue appears near the character

Clock and calendar are the primary visual elements.

## Direction

- Preserve the overall layout.
- Do not perform large-scale layout redesign without explicit instruction.
- Background decoration must not reduce clock/calendar readability.
- Continue improving visual balance without changing the app's core composition.

## Room Decoration

Recent improvement areas include:

- plant details
- radio
- hanging planter
- pendant light
- upper-right visual balance

These are secondary elements.
