# Calendar Specification

## Scope

The calendar is one of the two primary functions of Pixel Desk Clock.

## Current Direction

Keep existing working behavior stable, including:

- date calculation
- month display
- current-day display
- weekday display
- Japanese holiday handling

## Change Rule

Do not modify calendar logic for unrelated visual or background tasks.

## Expected Code Mapping

- CSS: `calendar.css`
- JS: `calendar.js`

If actual repository filenames differ, use `FILE_MAP.md`.
