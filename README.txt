Pixel Desk Clock v6.8.11 — 季節変化の土台

ZIPを展開しindex.htmlを開いてください。
差分更新：app.js、index.html、README.txt。新規：seasons.js、seasons.css。
v6.8.8を基準とした改善を継続し、起動フェードインは実装していません。

今回の範囲
・春→夏→秋→冬→春を端末の暦日で3日ごとに循環。
・初回起動日を春の1日目として数えます。実際の季節とは無関係。
・春は新緑と既存の小花、夏は深めの緑、秋は橙・黄・赤系、冬は葉を控えめに。
・各季節の3日目18〜24時に植物の色・花・葉の量を次の季節へ補間。
・カレンダー右上の隅に小花／葉／落ち葉／雪の結晶の小さな装飾。
・日付や今日の枠には装飾を重ねません。
・季節の開始日だけをLocalStorageへ保存（キー：pixelDeskClock.seasonAnchor.v1）。
・ページを閉じていた日数も含めて季節が進みます。保存不可ならその起動中のみ継続。
・既存の時計更新から同期し、非表示中の追加処理や新しいタイマーなし。
・画面全体の色フィルター、花びら、落ち葉の動き、天気、夏の入道雲はまだ追加しません。
・時計・背景6段階・キャラクター・雲・星・祝日・微小移動は維持。

手動確認
左下◆の2段目：季節AUTO／春／夏／秋／冬。
手動選択は保存せず、開始日にも影響しません。確認後は季節AUTOへ戻してください。
背景のAUTOは時間帯、季節AUTOは季節に対応し、独立しています。
